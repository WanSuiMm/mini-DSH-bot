# mini-DSH-bot 浏览器工作台

React、TypeScript 与 Vite 实现的同源浏览器任务工作台。静态入口使用 `/browser/`；API 请求固定到同源 `/v1/...`，由后端完成 Bearer 凭证校验。

## 构建入口

从本目录安装锁定依赖并生成静态资源：

```powershell
corepack pnpm install --frozen-lockfile --ignore-scripts
corepack pnpm run build
```

Vite 产物写入 `dist/`。服务端需将此静态产物挂载到 `/browser/`，并将 `/v1/` API 保持在同一来源。

## 安全与交互边界

- 访问凭证只保存在页面组件和 API 客户端内存中；退出、更换凭证或刷新会清空。请求不使用 Cookie，凭证不会写入 URL、存储区或日志。
- 页面只用 JPEG `<img>` 显示服务端截图，不嵌入网页、不渲染网页 HTML，也不自动请求页面观察。截图仅在会话活动且页面可见时刷新，间隔至少 3 秒，并保留最后一张有效图片。
- 导航和页面写入操作显示服务端返回的实际目标、引用和值；只有当前 Run 仍活动时才提供确认或拒绝。动作 `unknown` 显示“结果待核对”，不会提供重试入口。
- Run 提交使用一次生成的 `Idempotency-Key`。遇到断线或超时时按原 key 查询；未查明前不会自动重新提交。SSE 断线后按游标重连，前端最多保留 300 条事件。
